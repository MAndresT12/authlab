## 1. Empezar por service, porque el frontend va a necesitar endpoints contra los cuales pedir datos (login, registro). Si empezamos por React, estariamos maquetando pantallas que no tienen con que hablar todavia. El orden natural es: primero un servidor que responda algo, aunque sea minimo, y de ahi vamos creciendo.

# 2. Vamos a empezar creando rama de trabajo

git checkout develop
git pull
git checkout -b chore/server-setup (chore porque todavia no es una feature visible para el usuario final, es trabajo de infraestructura/andamiaje)

# 3. Inicializar proyecto de Node dentro de server/

cd server, pnpm init

# 4. Instalar express

pnpm add express

# 5. Instalar nodemon (solo desarrollo)

pnpm add --save-dev nodemon o pnpm add -D nodemon (abreviado)
nodemon reinicia el servidor automaticamente cada vez que se guarda un cambio

# 6. Agregar scripts al package.json creado al iniciar el proy

Es solo para ejecutar comandos
"scripts": {
"dev": "nodemon src/index.js",
"start": "node src/index.js"
}
