# 1. Una vez en client, creamos el proyecto con vite

pnpm create vite@latest . -- --template react-ts

# 2. Limpiar el boilerplate

src/main.tsx es el punto de entrada que monta REACT en el DOM, lo dejamos tal cual,
pero sobreescribiremos src/App.tsx y src/App.css despues.
Por ahora puedo borrar los assets por ejemplo.

# 3. Importante habilitar CORS en el servidor (server/)

Si no, el navegador va a bloquear las peticiones del frontend

cd ../server
pnpm add cors

y usar en server/src/index.js, antes de las rutas.
const cors = require('cors');
// ...
app.use(cors());

Los navegadores aplican Same-Origin Policy, una proteccion que por defecto bloquea que JavaScript corriendo en un origen (...:5173) haga peticiones a otro origen distinto (nuestra API en ...:4000 por ejemplo)
