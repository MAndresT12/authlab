# 6. Feature: frontend-token-handling

Vamos con el manejo de tokens, guardarlos, adjuntarlos automaticamente, y renovarlos solos cuando expiren

# 7. Vamos a usar axios, en lugar de fetch

pnpm add axios

Porque axios trae interceptores, funciones que se ejecutan automaticamente antes de que salga cada peticion, o despues de que llega cada respuesta, sin tener que repetir esa logica en cada componente. Eso es lo que se necesita para "inyectar el token en cada request" y "si da 401, renueva y reintenta" de forma centralizada.

# 8. Encapsular el acceso a localStorage

Crear client/src/lib/authStorage.ts
Tendre funciones para guardar tokens, acceder a ellos, sin necesidad de llamar localStorage. directo desde otro archivo, igualmente si en un futuro quisiese cambiar de localStorage a otra cosa, solo se toca ese archivo.

# 9. Crear client/src/lib/api.ts

Instancia de axios con interceptores, para evitar de colocar en cada llamada de la api
